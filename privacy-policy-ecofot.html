Política de Privacidad de EcoFot IA

Última actualización: 21/08/2026

1. Información general

EcoFot IA es una aplicación desarrollada por Aplicaciones HerrBri cuyo objetivo es ayudar al usuario a identificar el destino adecuado de un objeto o residuo mediante el análisis de una fotografía.

Esta política explica qué información puede tratar EcoFot IA, para qué se utiliza y qué servicios externos intervienen en el funcionamiento de la aplicación.

2. Datos personales

EcoFot IA no solicita al usuario datos personales como nombre, dirección, teléfono o fecha de nacimiento para utilizar sus funciones principales.

No obstante, determinados servicios técnicos integrados en la aplicación pueden procesar información como la dirección IP, identificadores del dispositivo, información técnica, datos de uso o datos de diagnóstico.

Las fotografías enviadas voluntariamente para su análisis podrían contener información personal visible, por ejemplo personas, documentos, matrículas u otros elementos identificables.

EcoFot IA no necesita que las fotografías contengan este tipo de información y se recomienda evitar incluir datos personales innecesarios en las imágenes.

3. Uso y procesamiento de las fotografías

EcoFot IA permite tomar o seleccionar una fotografía de un objeto o residuo para determinar el destino recomendado de acuerdo con el sistema de reciclaje configurado en la aplicación.

Cuando el usuario realiza un análisis:

  • La fotografía se envía a un servidor gestionado por el desarrollador.
  • El servidor procesa la solicitud y envía la información necesaria al servicio de inteligencia artificial de OpenAI.
  • OpenAI analiza la fotografía mediante su plataforma API y genera la información necesaria para determinar el resultado.
  • El resultado se devuelve al dispositivo del usuario.

En el servidor de EcoFot IA, la fotografía se procesa únicamente durante el tiempo necesario para gestionar la solicitud, enviarla al servicio de OpenAI y devolver el resultado al dispositivo.

EcoFot IA no guarda deliberadamente las fotografías enviadas para análisis en bases de datos ni en archivos permanentes del servidor. Una vez completada la solicitud, EcoFot IA deja de conservar la fotografía en sus propios sistemas.

El tratamiento que posteriormente realice OpenAI se rige por las condiciones, medidas de seguridad, políticas y períodos de conservación aplicables a su plataforma API.

4. País y región configurados

EcoFot IA necesita conocer el país y, cuando sea necesario, la región configurada por el usuario para aplicar correctamente las normas de reciclaje correspondientes.

Esta ubicación se selecciona manualmente dentro de la aplicación. EcoFot IA no necesita obtener la ubicación GPS del usuario para determinar el sistema de reciclaje aplicable.

La selección de país y región se guarda localmente en el dispositivo para recordar la configuración elegida.

5. Servicios de terceros

OpenAI - Procesamiento mediante inteligencia artificial

EcoFot IA utiliza servicios de inteligencia artificial proporcionados por OpenAI mediante su plataforma API para analizar las fotografías enviadas voluntariamente por el usuario y generar la información necesaria para ofrecer el resultado solicitado.

Cuando se realiza un análisis, la fotografía y las instrucciones técnicas necesarias para procesarla se envían desde el servidor de EcoFot IA a los servicios de OpenAI.

EcoFot IA limita la información enviada a OpenAI a la necesaria para realizar el análisis solicitado y no utiliza las fotografías para crear perfiles personales del usuario.

Según las condiciones aplicables a la plataforma API de OpenAI, los datos enviados a través de la API no se utilizan de forma predeterminada para entrenar los modelos de OpenAI, salvo que el cliente opte expresamente por compartirlos con ese fin.

OpenAI puede procesar y conservar temporalmente la información recibida de acuerdo con las condiciones, medidas de seguridad, políticas y períodos de conservación aplicables a su plataforma API.

El modelo concreto de OpenAI utilizado puede cambiar con el tiempo para mejorar la precisión, velocidad, disponibilidad o eficiencia del servicio, sin modificar la finalidad del tratamiento descrita en esta política.

Firebase Analytics

EcoFot IA utiliza Google Firebase Analytics para obtener estadísticas sobre el funcionamiento y uso de la aplicación.

Esta información puede incluir, entre otros:

  • Aperturas y sesiones de la aplicación
  • Interacción con determinadas pantallas y funciones
  • Información técnica sobre el dispositivo y la aplicación
  • País o ubicación aproximada derivada técnicamente

Estos datos se utilizan para conocer el uso de EcoFot IA, detectar problemas y mejorar la aplicación.

Firebase Crashlytics

EcoFot IA puede utilizar Google Firebase Crashlytics para detectar fallos, errores y problemas técnicos de la aplicación.

Este servicio puede procesar información técnica y de diagnóstico relacionada con el dispositivo, la aplicación y las circunstancias en las que se haya producido un error.

Publicidad - Google AdMob

EcoFot IA puede mostrar anuncios proporcionados por Google AdMob como parte de las modalidades de acceso financiadas mediante publicidad.

Google AdMob puede procesar información como:

  • Dirección IP
  • Identificadores del dispositivo o publicitarios
  • Ubicación aproximada
  • Interacciones con anuncios y con la aplicación
  • Información técnica y de diagnóstico

Dependiendo de la legislación aplicable y de las preferencias seleccionadas por el usuario, los anuncios pueden ser personalizados, no personalizados o limitarse a las funciones técnicas necesarias para su entrega.

Google User Messaging Platform (UMP)

EcoFot IA utiliza Google User Messaging Platform para gestionar, cuando sea necesario, las opciones de consentimiento y privacidad relacionadas con la publicidad y los servicios de Google.

Cuando esta opción está disponible, el usuario puede volver a consultar o modificar sus preferencias de privacidad desde la propia aplicación.

Google Play

EcoFot IA utiliza servicios de Google Play para la distribución de la aplicación, la gestión de actualizaciones y las compras realizadas dentro de la aplicación.

Las compras y suscripciones son procesadas por Google Play. El desarrollador no recibe los datos completos de la tarjeta bancaria ni otros datos financieros utilizados para efectuar el pago.

EcoFot IA puede recibir de Google Play la información técnica necesaria para verificar el estado de una compra o suscripción y habilitar las funciones adquiridas.

Política de privacidad de Google

Firebase, AdMob, Google User Messaging Platform y Google Play son servicios proporcionados por Google y están sujetos también a sus respectivas condiciones y políticas de privacidad.

Más información: Política de Privacidad de Google

Privacidad de OpenAI

El servicio de inteligencia artificial utilizado para analizar las fotografías es proporcionado por OpenAI mediante su plataforma API y está sujeto a las condiciones, medidas de seguridad y políticas aplicables a dicho servicio.

OpenAI indica que, de forma predeterminada, los datos enviados y recibidos mediante su plataforma API no se utilizan para entrenar ni mejorar sus modelos, salvo que el cliente opte expresamente por compartirlos con ese fin.

Más información:

  • Política de Privacidad de OpenAI
  • Privacidad empresarial y de la plataforma API de OpenAI

6. Uso de Internet

EcoFot IA requiere conexión a Internet para determinadas funciones, especialmente para realizar el análisis de fotografías mediante inteligencia artificial, mostrar publicidad, comprobar compras, gestionar actualizaciones y utilizar otros servicios externos necesarios para el funcionamiento de la aplicación.

7. Contacto y envío voluntario de información

EcoFot IA puede ofrecer al usuario la posibilidad de contactar con el desarrollador por correo electrónico, por ejemplo para comunicar un resultado incorrecto, informar de un problema o enviar comentarios sobre la aplicación.

  • El envío de esta información es voluntario.
  • El correo puede contener información proporcionada directamente por el usuario.
  • Si el usuario decide adjuntar fotografías, resultados u otros datos, estos serán recibidos por el desarrollador.
  • La información podrá utilizarse para responder al usuario, resolver el problema comunicado y mejorar EcoFot IA.

8. Finalidad y base jurídica del tratamiento

Dependiendo del tipo de información y de la legislación aplicable, los tratamientos realizados mediante EcoFot IA pueden basarse en:

  • La prestación de la función solicitada por el usuario, como el análisis de una fotografía.
  • El consentimiento del usuario cuando sea necesario, especialmente para determinados tratamientos relacionados con publicidad o tecnologías similares.
  • El interés legítimo en mantener la aplicación segura, detectar errores, prevenir abusos y garantizar su correcto funcionamiento, cuando dicha base jurídica sea aplicable.
  • El cumplimiento de obligaciones legales aplicables al desarrollador.

Cuando un tratamiento dependa del consentimiento, el usuario podrá retirarlo mediante las opciones disponibles o poniéndose en contacto con el desarrollador.

9. Conservación de los datos

Las fotografías enviadas para realizar un análisis no se almacenan permanentemente en los sistemas propios de EcoFot IA.

Los datos tratados por servicios externos como OpenAI, Firebase, AdMob o Google Play pueden conservarse durante los períodos establecidos por dichos proveedores y según la configuración y finalidad de cada servicio.

La información que el usuario envíe voluntariamente por correo electrónico podrá conservarse durante el tiempo necesario para responder, resolver la consulta o atender posibles responsabilidades legales.

10. Cuentas de usuario y eliminación de datos locales

EcoFot IA no requiere ni permite crear una cuenta de usuario. Por este motivo, no existe una cuenta personal de EcoFot IA que deba ser eliminada.

Las fotografías enviadas para realizar un análisis no se vinculan a una cuenta de usuario ni se almacenan permanentemente por EcoFot IA.

La información guardada localmente por la aplicación, como el país, la región y otras preferencias de funcionamiento, puede eliminarse borrando los datos de EcoFot IA desde los ajustes de Android o desinstalando la aplicación.

Las preferencias de privacidad y publicidad pueden consultarse o modificarse mediante las opciones de privacidad disponibles dentro de la aplicación cuando corresponda.

Determinados servicios externos utilizados por EcoFot IA, como OpenAI, Firebase, Google AdMob o Google Play, pueden tratar y conservar información técnica conforme a sus propias políticas y períodos de conservación.

11. Seguridad

Se aplican medidas técnicas y organizativas razonables destinadas a proteger la información tratada por EcoFot IA frente a accesos, pérdidas, alteraciones o usos no autorizados.

La comunicación entre la aplicación, el servidor de EcoFot IA y los servicios externos utilizados se realiza mediante conexiones cifradas cuando corresponde.

No obstante, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

12. Transferencias internacionales

Algunos proveedores tecnológicos utilizados por EcoFot IA pueden procesar información fuera de España o del Espacio Económico Europeo.

Cuando resulte aplicable la normativa europea de protección de datos, dichas transferencias deberán realizarse mediante los mecanismos y garantías previstos por la legislación correspondiente.

13. Derechos del usuario

Cuando resulte aplicable el Reglamento General de Protección de Datos (RGPD) u otra normativa equivalente, el usuario puede ejercer, según corresponda, los siguientes derechos:

  • Acceder a sus datos personales
  • Solicitar su rectificación
  • Solicitar su supresión
  • Solicitar la limitación del tratamiento
  • Oponerse a determinados tratamientos
  • Solicitar la portabilidad cuando sea aplicable
  • Retirar un consentimiento previamente otorgado

Para ejercer estos derechos, el usuario puede ponerse en contacto con el desarrollador mediante la dirección indicada al final de esta política.

El usuario también puede presentar una reclamación ante la autoridad de protección de datos competente. En España, la autoridad competente es la Agencia Española de Protección de Datos (AEPD).

14. Menores de edad

EcoFot IA no está diseñada ni dirigida específicamente a niños.

El desarrollador no solicita conscientemente datos personales de menores de edad a través de las funciones principales de la aplicación.

Si un padre, madre o tutor considera que un menor ha proporcionado información personal a través de EcoFot IA, puede ponerse en contacto con el desarrollador mediante los datos indicados en esta política para solicitar su revisión o eliminación cuando corresponda.

15. Cambios en esta política

Esta política de privacidad puede actualizarse cuando cambien las funciones de EcoFot IA, los servicios utilizados o las obligaciones legales aplicables.

La fecha indicada al comienzo de esta página permite conocer cuándo fue modificada por última vez.
